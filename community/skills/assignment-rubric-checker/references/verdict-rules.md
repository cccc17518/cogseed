# 判定规则（references/verdict-rules.md）

本规则定义 Skill 如何判定每条评分项的达成情况，以及如何从草稿原文定位证据。所有判定结论必须基于用户提供的草稿文本，任何情况下不得引入草稿之外的假设事实。

## 判定档位定义

- 满足：草稿中存在明确、完整的原文，覆盖该评分项的实质要求，无需用户补充即可判定。
- 部分满足：草稿中能定位到相关原文，但仅覆盖评分项的部分要求，或覆盖不完整、表述含糊。
- 未满足：评分项要求在草稿中无对应内容，或对应内容与要求明显不符。
- 无法判断：评分项要求不清晰、草稿对应内容缺失到无法对照，或两者口径无法对应；此时列为待确认问题，请用户补充，不得强行判定。

## 证据定位规则

1. 证据必须是用户提供的作业草稿原文片段，可含段落定位（如"草稿第2段""P3"）。
2. 证据引用原文，不做概括改写；确需说明时区分"草稿原文"与"合理推断"。
3. 草稿中不存在的功能、数据、引用、经历，一律不得补入证据。

## 与评分项的关系

- 每一条评分项独立判定，互不合并。
- 同一条评分项可同时命中多个证据片段，全部列出。
- 评分项要求含糊时，判定为"无法判断"并列入待确认问题，由用户澄清口径后再判。

## 输出红线

- 不给出总分、不合格/合格等单值结论。
- 每条判定必须给出原文证据支撑，无证据不下结论。
