# 输出模板（references/review-output-template.md）

Skill 的输出固定遵循以下结构。方括号及其中的说明文字在输出时替换为实际内容，各段顺序不得调换。

## 一、总体概览

- 作业与 rubric 的整体匹配情况：一句话总结达标概貌。
- 若因输入缺失而无法执行，此处直接说明缺失项，不展开其余段落。

## 二、逐项校验清单

每一条 rubric 评分项独立成块：

- 评分项原文：[rubric 条目]
- 草稿内对应证据：[引用原文片段，含段落定位]
- 判定结果：[满足 / 部分满足 / 未满足 / 无法判断]
- 改进建议：[可操作的修改方向]

## 三、缺失信息与待确认问题

固定结尾，逐条列出：
- 尚未提供的可选输入（此处声明默认假设）；
- 评分项要求不清、需用户澄清口径的条目；
- 需要用户决定的事项（如两条评分项要求互相冲突时的取舍）。
